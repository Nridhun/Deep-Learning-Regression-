Deep Learning Regression Project
Project Description

This project implements a Deep Learning model for a regression problem using Python and TensorFlow/Keras.

The goal is to train neural network models and predict the target value based on the given features.

Technologies Used
Python
NumPy
Pandas
Matplotlib
Scikit-learn
TensorFlow
Keras
Jupyter Notebook
Steps Performed
Loaded the dataset
Explored and understood the data
Prepared the features and target
Split the data into training and testing sets
Applied data preprocessing
Built Deep Learning regression models
Trained the models
Evaluated the models using:
Mean Squared Error (MSE)
Mean Absolute Error (MAE)
R² Score
Compared the model results
Results

The models were evaluated using MSE, MAE, and R² score to understand their prediction performance.

Conclusion

This project helped me understand how Deep Learning models can be used for regression problems. I learned how to prepare data, build neural networks, train models, and evaluate their performance using different regression metrics.
